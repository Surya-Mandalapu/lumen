# Southern hemisphere exploration

The hemisphere explorer now opens directly on the topographic Moon, textured
Earth/Sun context and orbital timeline. The previous recommendation-card block,
duplicated introductory text and separate whole-Moon workspace tab were removed
to reduce the amount of UI before the model.

Choose a point by clicking the Moon or a visible landmark label. **Find a place**
opens the approved landmark search in the study-area panel. Coordinates remain
keyboard editable, and up to six areas can be saved on the device.

Coarse date-specific point previews cover the entire southern hemisphere.
Detailed candidate ranking uses the advertised prepared polar dataset: a local
search radius up to 5 km and live windows up to seven days, or the exact cached
October 1–31, 2028 full-region demonstration. A partial prepared intersection
requires acknowledgment before analysis. The global visual model does not imply
that detailed terrain/horizon analysis exists everywhere.

The latency requirement is now measured as successful average completion below
30 seconds per search type. Requests are not cut off at 30 seconds. See
[the orbital planner guide](orbital-planner.md) for current controls, data sources,
installation, timing measurements, safety-watchdog behavior and verification.
