# Stealth Lumen

Stealth Lumen is a planned hackathon web application for comparing candidate lunar south-pole landing sites using terrain, illumination, and geometric direct-to-Earth visibility indicators.

See the [product and implementation plan](./LUNAR_LANDING_SITE_PLAN.md).

> This project is a prototype planning tool, not flight-certified mission-planning software and not a landing-safety certification system.
